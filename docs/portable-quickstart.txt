一、这是什么
------------
让 AI Agent 接管 ParaTranz 汉化项目的全流程：
分派任务 → 批量翻译 → 自动校对 → 整理术语 → 发布规范，
以及「游戏文件 ↔ 平台」的双向链路（提取词条 / 回写译文）。


二、怎么启动
------------
双击 web.bat        —— 打开可视化控制台（浏览器自动打开 http://127.0.0.1:8787）
双击 ptz.bat        —— 命令行（等价于 ptz 命令，参数照传）

想看界面但还没有 Token？
    web.bat --mock
内置假平台演示，完整跑一遍五条流水线，不碰真实项目。


三、第一次使用要填两样东西
--------------------------
1) 「项目」页：ParaTranz API Token + 项目编号，点「测试连接」
   Token 在 paratranz.cn → 头像 → 设置 → 开放接口 里生成
2) 「模型」页：一个 OpenAI 兼容的 API（地址 / Key / 模型名）
   可点「获取模型列表」自动探测可用模型

两样都填好，就能在「概览」页直接下指令，或到各页面点按钮。
没配模型时不会假装在跑——会直接提示你去配置。


四、数据存在哪
--------------
本目录下的 .ptz-state\ 文件夹（Token、Key、任务记录、提取记录都在这里）。
备份就复制这个文件夹；换机器就把它一起带走。
凭据只存在本机，接口只回显尾号，日志与错误信息自动脱敏。


五、常见问题
------------
· 双击没反应 / 一闪而过
  用命令行进到本目录执行 web.bat，能看到具体报错。

· 杀毒软件报毒
  这是绿色包（自带官方 Python 运行时），部分杀软对「解压即用的 exe」敏感。
  加信任即可，源码全公开。

· 浏览器没自动打开
  手动访问 http://127.0.0.1:8787

· 提示端口被占用
  web.bat --port 8788

· 想改成本机常驻
  ptz.bat watch       有活就干，没活就等

· 命令行写操作默认是「演练」
  所有写操作都要显式加 --yes 才真正落地。
